Signature is lowercase hex HMAC-SHA256 of UTF8 JSON array of all preceding fields in that exact order. Tick payload digest is SHA256 UTF8 JSON([kind,producer_seq,occurred_at,scheduled_for,version]). scheduled_for is ORIGINAL ScheduledController.scheduledTime passed explicitly through the internal DO command; no fallback. occurred_at is actual durable enqueue time; head deadline remains original occurred_at+60000. Existing ACK14 signed fields and ACK_RECOVERY remain unchanged.

Lifecycle and transition envelope extension adds payload immediately before signature as an exact additional field. HMAC tuple is the same preceding common array followed by recursively key-sorted canonical JSON string of payload. Extended payload_digest is SHA256 of that canonical payload string. Kind allowlist is canary-lifecycle, ATTEMPT_RESERVED, BREAKER_OPEN, BREAKER_CLOSED; no unknown arbitrary kind. This seals monitor acceptance for future producers, without claiming those producers implemented. Strict configured source kind allowlists and credential tuples are mandatory.

Lifecycle payload: source_id, monotonic_seq, transition_id, state ('unknown'|'healthy'|'failed'), transition_at, source_version, sampled_at, nonce. These exact fields retain DO-authored six-field authority and sampler proof. Registration pins source_id/source_version; nonce nonempty and changed on each delivery; source transition sequence can equal only with byte-identical six-field authority tuple; transition time cannot be future relative to sampled_at; sample age 0..120000ms and at most30000ms future skew is producer route rule, while monitor future envelope refuses until valid.
