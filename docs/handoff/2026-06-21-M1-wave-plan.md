# M1 WAVE PLAN — multi-tenant control plane (decision record)

> **Tech lead:** CoreLink Runners TL · **Date:** 2026-06-21 · derived from the `m1-recon` fleet wave
> (6 agents, 5 dimensions mapped + synthesis). This is the dispatch decision record (techlead Section 3).

## Current state (recon verdict)
The execution **data plane + per-tenant ENFORCEMENT are real + tested**: Bearer-PAT → `TenantId`
(`auth.rs`), per-tenant concurrency cap + rate ceiling (`caps.rs`), cross-instance cap-safe admission via
Postgres advisory lock (`pg_ledger.rs`), durable billing-event export keyed `(tenant,lease_id,kind,at_ms)`
(`billing_export.rs`/`PgBillingSink`), and the frozen public lease/exec/close/usage API (`paths.rs`).
**What blocks "sellable to MULTIPLE paying tenants" is the PROVISIONING + IDENTITY + MONETIZATION layer,
not the fabric.** Today: admin onboarding writes only to an in-memory registry (lost on restart); the
CoreLink-introspect path authenticates any tenant but resolves 0-cap (introspect omits `max_concurrency`);
zero Stripe/invoice code; no self-serve signup; no plan up/downgrade API; no per-tenant audit trail; no
tenant lease-history/usage read surface.

## Lead decisions (defaults I'm proceeding on — redirect any)
1. **M1 sells via the operator-provisioned-PAT + DURABLE store path** (the WP-PERSIST cluster), NOT the
   CoreLink-introspect path (cross-repo-blocked) and NOT self-serve signup (ADR-0002 defers Clerk to M2).
2. **Billing vendor: ship the SEAM + no-op adapter only** (WP-STRIPE-SEAM); the real Stripe-vs-corelink-billing
   adapter is OWNER-gated → deferred, not built.
3. **WP-CORELINK-CEILING DEFERRED** — consumer of an introspect `max_vcpu_h` vector that must be a
   corelink-server PR first (owner/CoreLink-TL gate). Not in this wave.
4. **Downgrade = grace-to-expiry** (existing Held leases honored; new acquires gated at new cap).
5. **Global instance ceiling = configurable** (hard-gate vs advisory by config; default advisory).
6. **vCPU-h ceiling = default-ON per provisioned tier** (revenue protection); dogfood stays opt-in initially.
